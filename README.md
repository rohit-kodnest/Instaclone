# InstaClone

A simple Instagram clone built using HTML, Tailwind CSS, and JavaScript.

## How to Run

Open `index.html` in a browser to view the InstaClone.

This project consists of fundamental features like a header, search bar, sample posts, and navigation links arranged using Tailwind CSS and JavaScript. You can expand upon this by adding more functionalities such as user authentication, comments, likes, etc.
